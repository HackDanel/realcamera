# RealCamera

Мод на реалистичную фотографию для Minecraft **1.21.1 / NeoForge**. Личная сборка, не для публикации:
в моде используются настоящие названия брендов и моделей камер.

Полный план функционала: `docs/` и план проекта. Итоги этапа 0: `docs/stage0-capture.md`.

## Что нужно установить

Только **Java** любой версии от 21 и выше (сейчас в системе есть 25, этого достаточно для запуска Gradle).
Нужный для Minecraft 1.21.1 JDK 21 Gradle скачивает сам при первой сборке.

## Команды (запускать из папки проекта)

| Команда | Что делает |
|---|---|
| `./gradlew build` | Собирает мод. Готовый файл: `build/libs/realcamera-<версия>.jar` |
| `./gradlew runClient` | Запускает Minecraft с модом (+ Sodium и Iris) для проверки |
| `./gradlew runClient2` | Второй клиент (ник Player2) — для проверки мультиплеера |
| `./gradlew runServer` | Выделенный сервер с модом. **Перед первым запуском** нужно самому принять EULA Minecraft: открыть `run/eula.txt` и поставить `eula=true` |
| `./gradlew runClientAutotest` | Автотест захвата кадра: сам создаёт мир, делает снимки и закрывает игру |
| `./gradlew test` | Автоматические тесты |

Первый запуск долгий (скачивается Minecraft и NeoForge), дальше быстрее.

## Установка в обычный лаунчер

1. Установи NeoForge 21.1.x для Minecraft 1.21.1 (например, через Prism Launcher).
2. Положи `build/libs/realcamera-<версия>.jar` в папку `mods` этого профиля.
3. По желанию добавь Sodium и Iris (NeoForge-версии для 1.21.1) и шейдерпак — мод снимает с шейдерами.

## Как попробовать (этап 1)

В творческом режиме открой вкладку **RealCamera**. Первым предметом там лежит готовая к съёмке камера:
Sony α7 IV с объективом, заряженным аккумулятором и картой памяти.

| Действие | Управление |
|---|---|
| Поднять камеру к глазу | удерживать ПКМ (только от первого лица) |
| Сделать снимок | ЛКМ (сначала наводится автофокус) |
| Зум (у зум-объектива) | колесо мыши |
| Выбрать параметр (выдержка, диафрагма, ISO, EV, баланс белого) | Z / X |
| Изменить выбранный параметр | Ctrl + колесо (у фикс-объектива — просто колесо) |
| Ручной фокус (в режиме MF) | Alt + колесо |
| Режим Auto / P / A / S / M | M |
| Режим фокуса AF-S / AF-C / MF | F |
| Вид информации в видоискателе | Tab |
| Просмотр снимков на камере | P |
| Меню камеры | G |
| Открыть камеру (объектив, аккумулятор, карта) | Shift + ПКМ |

Дальше: поставь **фотопринтер**, вставь карту, фотобумагу и картриджи, выбери снимок и нажми «Печать».
Отпечаток можно рассмотреть (ПКМ) или вставить в **фоторамку** на стене (Shift + ПКМ по рамке меняет паспарту).
Аккумулятор заряжается в **зарядном устройстве**, на которое подан сигнал редстоуна.
Всё оборудование собирается в **фотомастерской** (сама она крафтится на обычном верстаке).

Каждый снимок сразу сохраняется полноразмерным JPEG с настоящим EXIF в `screenshots/realcamera/<дата>/`.

Команды администратора: `/photo list`, `/photo info <id>`, `/photo delete <id>`, `/photo purge <игрок>`, `/photo stats`.

## Для разработки

- `./gradlew runClientAutotest` — сквозной автотест этапа 1: сам строит сцену, снимает, печатает, вешает рамку,
  открывает все экраны и кладёт скриншоты в `run-autotest/screenshots/autotest/`. Результат — строки `[autotest] PASS/FAIL` в логе.
- `python3 tools/gen_assets.py` — пересоздаёт текстуры, модели и звуки; `python3 tools/gen_recipes.py` — рецепты.
