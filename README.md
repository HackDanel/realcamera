# RealCamera

Мод на реалистичную фотографию для Minecraft **1.21.1 / NeoForge**. Некоммерческий фанатский проект.

> **Дисклеймер.** Проект не связан с Sony, Canon, Nikon, Fujifilm, Hasselblad, Leica, Panasonic, OM System,
> Pentax, Ricoh, Sigma, Tamron, Samyang, Godox, Kodak, Ilford, CineStill и другими производителями и не одобрен ими.
> Названия камер, объективов и плёнок используются только чтобы описать реальную технику; все товарные знаки
> принадлежат их владельцам. Текстуры, модели и звуки мода нарисованы и синтезированы скриптами проекта
> (`tools/gen_assets.py`), изображения производителей не используются.
>
> *Not affiliated with or endorsed by any camera, lens or film manufacturer. Product names are used only to
> describe real equipment; all trademarks belong to their owners. All textures, models and sounds are generated
> by the project's own scripts.*

Полный план функционала: `docs/` и план проекта. Итоги этапа 0: `docs/stage0-capture.md`.

## Что нужно установить

Только **Java** любой версии от 21 и выше (сейчас в системе есть 25, этого достаточно для запуска Gradle).
Нужный для Minecraft 1.21.1 JDK 21 Gradle скачивает сам при первой сборке.

## Команды (запускать из папки проекта)

| Команда | Что делает |
|---|---|
| `./gradlew build` | Собирает мод. Готовый файл: `build/libs/realcamera-<версия>.jar` |
| `./gradlew runClient` | Запускает Minecraft с модом (+ Sodium и Iris) для проверки |
| `./gradlew runClient2` | Второй клиент (ник Player2) — для проверки мультиплеера |
| `./gradlew runServer` | Выделенный сервер с модом. **Перед первым запуском** нужно самому принять EULA Minecraft: открыть `run/eula.txt` и поставить `eula=true` |
| `./gradlew runClientAutotest` | Автотест захвата кадра: сам создаёт мир, делает снимки и закрывает игру |
| `./gradlew test` | Автоматические тесты |

Первый запуск долгий (скачивается Minecraft и NeoForge), дальше быстрее.

## Установка в обычный лаунчер

1. Установи NeoForge 21.1.x для Minecraft 1.21.1 (например, через Prism Launcher).
2. Положи `build/libs/realcamera-<версия>.jar` в папку `mods` этого профиля.
3. По желанию добавь Sodium и Iris (NeoForge-версии для 1.21.1) и шейдерпак — мод снимает с шейдерами.

## Как попробовать

В творческом режиме открой вкладку **RealCamera**. Первым предметом там лежит готовая к съёмке камера:
Sony α7 IV с объективом, заряженным аккумулятором и картой памяти.

| Действие | Управление |
|---|---|
| Поднять камеру к глазу | удерживать ПКМ (только от первого лица) |
| Сделать снимок | ЛКМ (сначала наводится автофокус) |
| Зум (у зум-объектива) | колесо мыши |
| Выбрать параметр (выдержка, диафрагма, ISO, EV, баланс белого) | Z / X |
| Изменить выбранный параметр | Ctrl + колесо (у фикс-объектива — просто колесо) |
| Ручной фокус (в режиме MF) | Alt + колесо |
| Режим Auto / P / A / S / M | M |
| Режим фокуса AF-S / AF-C / MF | F |
| Вид информации в видоискателе | Tab |
| Просмотр снимков на камере | P |
| Меню камеры | G |
| Режим вспышки (выкл, заполняющая, по второй шторке, авто) | V |
| Лупа для ручного фокуса | H |
| Режим съёмки (покадровый, серии, таймер) | B |
| Зона автофокуса (широкая, зона, точка, трекинг) | N |
| Сдвинуть точку автофокуса | стрелки |
| AF-ON: навести фокус без снимка (дальше ЛКМ снимает без перефокусировки, в AF-C — следит, пока держишь) | R |
| Открыть камеру (объектив, адаптер, телеконвертер, фильтр, вспышка, аккумулятор, ручка, карта) | Shift + ПКМ |

Видоискатель показывает глубину резкости как на будущем снимке (при выставленной диафрагме): видно, как наводится
фокус. Отключается в настройках мода («Глубина резкости в видоискателе»); у дальномерных камер её нет. С шейдерпаком
работает тоже; если в самом шейдерпаке включена своя глубина резкости, лучше выключить одну из двух. Автофокусу нужна деталь: на чистом небе или гладкой стене объектив «рыщет» и сдаётся (кадр не снимается),
на слабой детали наводится дольше и менее точно. Траву и цветы автофокус видит.

Дальше: поставь **фотопринтер**, вставь карту, фотобумагу и картриджи, выбери снимок и нажми «Печать».
Отпечаток можно рассмотреть (ПКМ) или вставить в **фоторамку** на стене (Shift + ПКМ по рамке меняет паспарту).
Размер рамки ограничен бумагой: отпечаток 10×15 или A5 — только в рамку 1×1, A4 — до 2×2, A3 — в любую
(подсказки отпечатка и рамки это показывают). Настольная рамка, фотостенд и альбом принимают любой отпечаток.
Аккумулятор заряжается в **зарядном устройстве**, на которое подан сигнал редстоуна (туда же — батарейные ручки и вспышки).
**Штатив**: поставь на землю, ПКМ камерой — закрепить, ПКМ пустой рукой — смотреть через камеру, Shift — отойти.
С таймером на 10 с можно отойти и попасть в кадр самому.
Техника изнашивается: вода и дождь (без защиты от влаги), падения, пыль при смене объектива, ресурс затвора.
Чинится в фотомастерской, пыль и влагу убирает набор для чистки.
Всё оборудование собирается в **фотомастерской** (сама она крафтится на обычном верстаке).

Каждый снимок сразу сохраняется полноразмерным JPEG с настоящим EXIF в `screenshots/realcamera/<дата>/`.
В режиме RAW рядом ложится `.PNG` (16-битные линейные данные матрицы, выглядит тёмным, как непроявленный RAW)
и `.json` с параметрами съёмки.

**Компьютер**: вставь карту памяти (два слота: A и B, для CFexpress нужен картридер). Каталог показывает
снимки карты: клик выбирает, двойной клик или «Править» открывает редактор, звёзды под миниатюрой ставят
рейтинг, «Копир.→» и «Перен.→» переносят снимок на другую карту, «Форматир.» (нажать дважды) очищает карту.

**Редактор**: вкладки «Свет» (экспозиция, контраст, света, тени, белые, чёрные), «Цвет» (температура,
оттенок, сочность, насыщенность, ч/б, профиль камеры для RAW), «Кривая» (тяни точки), «HSL» (8 цветов),
«Детали» (резкость, шумоподавление, виньетка, зерно, профиль объектива), «Кадр» (пропорции, поворот,
горизонт, рамку кадрирования тянуть мышью), «Пресеты» (сохранить свои). Ctrl+Z / Ctrl+Y — отмена и повтор,
`\` — до/после. Из RAW можно вытянуть пересвеченное небо, из JPEG — нет. Автор снимка редактирует
полноразмерный оригинал со своего компьютера, остальные — игровую копию.
«Сохранить копию» кладёт результат новым снимком на ту же карту, «Экспорт на ПК» пишет полноразмерный JPEG
с EXIF в `screenshots/realcamera/export/`.

**Плёнка.** Плёночные камеры (Nikon FM2, Leica M6, Canon EOS-1V) снимают на ролики плёнки (Portra, Ektar,
Gold, Tri-X, HP5, Delta 3200, Velvia, Provia, CineStill 800T), плёнка вставляется в слот карты (Shift+ПКМ).
ISO выставляется на камере, как в жизни: у механических камер (FM2, M6, K1000, OM-1, AE-1P, Зенит) это диск
без автомата — сначала стоит на чувствительности плёнки, а выставленное значение остаётся при смене ролика, так что
помни, какая плёнка заряжена. EOS-1V читает DX-код плёнки, но его можно перебить; Contax T2 берёт ISO только с
DX-кода; у Hasselblad экспонометра нет, ISO выставлять негде. Отличное от плёнки ISO (от −1 до +3 ступеней)
HUD показывает рядом («ISO 1600 +2.0») — такую плёнку потом надо пушить или пуллить при проявке. Экрана нет: кадры увидишь только после проявки. Негатив прощает переэкспозицию,
слайд — нет; на длинных выдержках плёнка теряет чувствительность (эффект Шварцшильда). Механические камеры
(FM2, K1000, OM-1, M6, Зенит, Hasselblad) — только ручной режим M, без батарейки у них не работает экспонометр
(у Зенита селеновый экспонометр, у Hasselblad его нет). Когда плёнка кончится, перемотай её (меню G,
«Перемотать плёнку»). Если вынуть неперемотанную плёнку на свету, засветятся последние кадры (плёнку 120
перематывать не нужно).
**Проявочный бак**: плёнка + нужная химия (C-41 для цветного негатива, E-6 для слайдов, ч/б), пуш/пул, «Проявить».
Заряжать бак нужно в полной темноте (без красного фонаря рядом) или с **зарядным рукавом** в слоте бака.
Проявленную плёнку можно рассмотреть (ПКМ), напечатать на **фотоувеличителе** на фотобумаге для лаборатории
(RC, баритовая, RA-4) или отсканировать в **компьютере** со **сканером плёнки**. Увеличителю нужна химия для бумаги
(ч/б химия, для цветной бумаги RA-4 — цветная C-41). Фотобумагу у увеличителя можно держать только в темноте или
при **красном фонаре**, иначе отпечаток засветится; цветной бумаге RA-4 нужна полная темнота. Слайд на негативной
бумаге печатается негативом.

**Фотоальбом** (книга + кожа + 3 бумаги): ПКМ — открыть, «Вставить отпечаток» берёт отпечаток из второй
руки или инвентаря, под фото можно написать подпись. Положи альбом на кафедру, и его смогут листать все.
**Настольная рамка** ставится на стол или полку (как голова — в 16 направлений, по взгляду игрока), **фотостенд** (мольберт в два блока) — для выставок.
ПКМ отпечатком — вставить, ПКМ пустой рукой — посмотреть, Shift+ПКМ — забрать.

**Полный каталог** (этап 6): 39 камер и 63 объектива — Sony, Nikon, Canon, Fujifilm, Panasonic, Leica, OM System,
Hasselblad, плюс плёночные Canon AE-1, Pentax K1000, Olympus OM-1, Зенит-Е, Hasselblad 500C/M (плёнка 120, кадр 6×6)
и Contax T2. У компактов (Fujifilm X100VI, Leica Q3, Contax T2) объектив встроен и не снимается. Для чужих
объективов есть адаптеры (M42, Leica M, Canon FD, Pentax K, Olympus OM, Hasselblad V…) и телеконвертеры.
Особая оптика:
- **фишай** (M.Zuiko 8mm, Samyang 8mm) — сильная бочка, на полном кадре — круглая картинка;
- **тилт-шифт** Canon TS-E 24mm: Z / X выбирают «TILT» и «SHIFT», Ctrl+колесо меняет. Сдвиг (shift) держит
  вертикали зданий параллельными, наклон (tilt) поворачивает плоскость резкости («игрушечный город» при
  обратном наклоне). В видоискателе вертикали ещё сходятся, на снимке они ровные;
- **макро 1:1** (Sony 90mm, Nikon MC 105mm, Canon RF 100mm, Fujifilm 80mm): в видоискателе видно увеличение «1:2.5»,
  кадр сужается при приближении, глубина резкости — доли миллиметра, на 1:1 теряется 2 ступени света. У обычных
  объективов максимальное увеличение настоящее (зумы — около 1:3–1:5);
- **винтаж**: Гелиос-44-2 закручивает боке в вихрь, Trioplan даёт «мыльные пузыри».
Старая техника попадается в сундуках: у картографов в деревнях (плёнка, Зенит, Гелиос), на затонувших кораблях
(утонувшие камеры на запчасти), в кладах и библиотеках крепостей (Leica M6, Hasselblad), в древних городах и
испытательных залах (многослойные и среднеформатные матрицы, Contax T2).

**Игровые цели** (этап 7). Сервер сам смотрит, что попало в кадр: существа (резкие или нет, какого размера),
небо, солнце и луна, погода, закат, молния, звёздные треки на штативе. Каждый снимок получает оценку от одной до трёх
звёзд — её видно в подсказке отпечатка. **Фотоэнциклопедия** (клавиша **J** или полевой журнал) собирает страницы
существ, биомов, измерений и явлений с лучшим снимком каждого. Во вкладке достижений RealCamera — 37 достижений
(«Тихо, Варден», «Звёздный путь», «Охотник за драконом», «Весь мир в объективе»…).
**Редактор газеты** — житель, которому нужен **редакционный стол** (бумага, чернильный мешок, доски): он даёт
заказы на снимки («панда в бамбуковых джунглях, 2★») и платит изумрудами за подходящий отпечаток. Покупает только
твои собственные снимки и каждый снимок только один раз (перепечатки и правки того же кадра не пройдут);
отпечаток без чернил или засвеченный не примут. Биом считается там, куда наведён фокус.

**Реалистичная экспозиция.** Экспонометр знает реальную освещённость: в тени под навесом на 2–3 ступени темнее,
ночь при полной луне около EV −2,5, без луны — около −9, в дождь и грозу заметно темнее. Правильно
экспонированный ночной снимок получается светлым, как у настоящей камеры, но для этого нужен штатив или высокий
ISO. Снег и белые предметы обманывают экспонометр (снимок темнее), тёмные — наоборот. Шум зависит от ISO и
размера матрицы (полный кадр чище APS-C и Micro 4/3), у факела тёплый свет около 1900 K. RAW сохраняется без
коррекций объектива.
**Камеры ведут себя как настоящие**: у каждой своя автономность по CIPA, буфер серии и скорость карты, свои типы
затвора (у зеркалок нет электронного), вспышка с электронным затвором только у быстрых матриц (Z8, Z9, α1 II…),
в авто-режимах со вспышкой выдержка не короче синхронизации. Hasselblad X2D хранит снимки во встроенном SSD:
положи камеру целиком в компьютер или принтер (как по USB) — так можно и с любой цифровой камерой.

**Вспышка в мультиплеере**: чужую вспышку видят все вокруг. Насколько она яркая, считается по-настоящему — по
ведущему числу и мощности, которую выбрал TTL, расстоянию и тому, сколько света уже есть: ночью вспышка в 10 м
освещает всё как днём, на солнце её почти не заметно. Свет идёт конусом по оси объектива и не проходит сквозь стены;
если смотреть прямо в неё, остаётся блик и цветное «пятно в глазах» (оно двигается вместе со взглядом). Чем ярче
вспышка относительно того, к чему привыкли глаза (ночью, близко, на полной мощности), тем сильнее блик, больше и
дольше пятно — до ~8 секунд; слабая вспышка днём — лишь искорка. Свою вспышку фотограф тоже видит: сцена вспыхивает
сразу после снимка, но без блика и «пятна в глазах» (и с руки, и со штатива). Если в это время у тебя открыт
затвор (длинная выдержка), чужая вспышка попадёт в твой кадр — с тенями и спадом света с расстоянием.

**Как держат камеру**: правая кнопка поднимает камеру к глазу (за четверть секунды), видоискатель включается, когда
она у глаза; при отпускании камера опускается. Другие игроки видят, что ты держишь камеру двумя руками у лица.
Камера, которая лежит в инвентаре (не в руке), висит на ремне на груди — её видно всем вокруг.

**Фильтры**: UV, поляризационный, ND8/ND64/ND1000, градиентный GND8 (затемняет небо, верхнюю половину кадра),
Black Mist 1/4 и 1/8 (мягкое свечение вокруг светлого, ниже контраст), звёздный 6x (лучи от ярких точек: фонари,
звёзды), цветные для ч/б (жёлтый, оранжевый, красный, зелёный) и для цвета (синий 80A, янтарный 85). Размеры
67/77/82/95/112 мм (не все типы во всех размерах). Фильтр накручивается прямо на объектив, если его диаметр равен
резьбе объектива; 112 мм — для Nikon Z 14-24/2.8. На фишаи и компакты фильтр не ставится. Резьба объектива — в его
подсказке.

**Повышающие кольца**: чтобы поставить фильтр большего диаметра, нужно кольцо с резьбы объектива на размер фильтра
(39→67, 49→67, 55→67, 58→67, 62→67, 67→77, 72→77, 77→82, 82→95, 95→112 и др.; на кольцо встаёт любой фильтр не
меньше его выходного размера). Собираются в мастерской из железных самородков и чёрного красителя. Как собрать:
- в инвентаре — ПКМ кольцом по фильтру (или фильтром по кольцу): получится фильтр на кольце, его и ставят в камеру;
- прямо в камере — положи кольцо в ячейку фильтра, потом кликни фильтром по кольцу.

ПКМ пустым курсором по фильтру на кольце — открутить: в инвентаре кольцо отдаётся в курсор, а в камере кольцо
остаётся на объективе, фильтр — в курсор. Снятый из камеры фильтр уносит своё кольцо с собой — ничего не теряется.

**Шейдерпаки**: мод подстраивается под любой шейдерпак Iris, не только под Complementary. Яркость снимка считается
по тому, что шейдерпак реально нарисовал (у паков разная яркость ночи, своя автоэкспозиция), поэтому правильная
экспозиция даёт правильный снимок. Если шейдерпак не кладёт настоящую глубину в буфер, мод это замечает: снимок
берёт глубину по лучам, а глубина резкости в видоискателе выключается, пока шейдерпак не сменят.
С шейдерпаком снимок делается в разрешении окна (кадр обрезается под пропорции матрицы), а не в разрешении
матрицы: смена размера окна сбрасывает шейдерпаку автоэкспозицию и накопление кадров (у IterationT из-за этого был
серый снимок с надписью «Iteration 3.2.0»). Для большего разрешения снимка разверни окно на весь экран. Если у
шейдерпака своя глубина резкости, она фокусируется туда же, куда объектив, а не в центр экрана.

**JEI, EMI, REI** (этап 8): если стоит любой из них, там видны рецепты фотомастерской, проявка плёнки по
процессам и печать на фотоувеличителе. Без них мод работает как обычно.

Команды администратора: `/photo list`, `/photo info <id>`, `/photo delete <id>`, `/photo purge <игрок>`, `/photo stats`.

## Для разработки

- `./gradlew runClientAutotest -Pautotest=stage8 -Pviewer=jei` (или `emi`, `rei`) — рецепты в просмотрщике.
- `./gradlew runClient -Pviewer=jei` — запустить игру с JEI (или EMI/REI) для проверки.
- `./gradlew runClientAutotest -Pautotest=stage7` — анализ кадра, энциклопедия, достижения, заказ редактора газеты.
- `./gradlew runClientAutotest -Pautotest=stage6` — каталог, витрина камер и объективов, фишай, тилт-шифт, макро, Гелиос, X100VI, плёнка 120, лут.
- `./gradlew runClientAutotest -Pautotest=stage3` — автотест аксессуаров и износа (вспышка, фильтры, штатив, вода, ремонт).
- `./gradlew runClientAutotest -Pautotest=stage2` — автотест оптики этапа 2 (адаптеры, видоискатели, длинные выдержки, серия).
- `./gradlew runClientAutotest` — сквозной автотест этапа 1: сам строит сцену, снимает, печатает, вешает рамку,
  открывает все экраны и кладёт скриншоты в `run-autotest/screenshots/autotest/`. Результат — строки `[autotest] PASS/FAIL` в логе.
- `python3 tools/gen_assets.py` — пересоздаёт текстуры, модели и звуки; `python3 tools/gen_recipes.py` — рецепты.
- Каталог этапа 6 описан в `tools/catalog.py`: `python3 tools/gen_catalog.py` пишет JSON и названия, потом
  `gen_assets.py` и `gen_recipes.py`; лут в сундуках — `python3 tools/gen_loot.py`; достижения — `python3 tools/gen_advancements.py`.
