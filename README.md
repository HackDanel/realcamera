# RealCamera

Мод на реалистичную фотографию для Minecraft **1.21.1 / NeoForge**. Личная сборка, не для публикации:
в моде используются настоящие названия брендов и моделей камер.

Полный план функционала: `docs/` и план проекта. Итоги этапа 0: `docs/stage0-capture.md`.

## Что нужно установить

Только **Java** любой версии от 21 и выше (сейчас в системе есть 25, этого достаточно для запуска Gradle).
Нужный для Minecraft 1.21.1 JDK 21 Gradle скачивает сам при первой сборке.

## Команды (запускать из папки проекта)

| Команда | Что делает |
|---|---|
| `./gradlew build` | Собирает мод. Готовый файл: `build/libs/realcamera-<версия>.jar` |
| `./gradlew runClient` | Запускает Minecraft с модом (+ Sodium и Iris) для проверки |
| `./gradlew runClient2` | Второй клиент (ник Player2) — для проверки мультиплеера |
| `./gradlew runServer` | Выделенный сервер с модом. **Перед первым запуском** нужно самому принять EULA Minecraft: открыть `run/eula.txt` и поставить `eula=true` |
| `./gradlew runClientAutotest` | Автотест захвата кадра: сам создаёт мир, делает снимки и закрывает игру |
| `./gradlew test` | Автоматические тесты |

Первый запуск долгий (скачивается Minecraft и NeoForge), дальше быстрее.

## Установка в обычный лаунчер

1. Установи NeoForge 21.1.x для Minecraft 1.21.1 (например, через Prism Launcher).
2. Положи `build/libs/realcamera-<версия>.jar` в папку `mods` этого профиля.
3. По желанию добавь Sodium и Iris (NeoForge-версии для 1.21.1) и шейдерпак — мод снимает с шейдерами.

## Как попробовать

В творческом режиме открой вкладку **RealCamera**. Первым предметом там лежит готовая к съёмке камера:
Sony α7 IV с объективом, заряженным аккумулятором и картой памяти.

| Действие | Управление |
|---|---|
| Поднять камеру к глазу | удерживать ПКМ (только от первого лица) |
| Сделать снимок | ЛКМ (сначала наводится автофокус) |
| Зум (у зум-объектива) | колесо мыши |
| Выбрать параметр (выдержка, диафрагма, ISO, EV, баланс белого) | Z / X |
| Изменить выбранный параметр | Ctrl + колесо (у фикс-объектива — просто колесо) |
| Ручной фокус (в режиме MF) | Alt + колесо |
| Режим Auto / P / A / S / M | M |
| Режим фокуса AF-S / AF-C / MF | F |
| Вид информации в видоискателе | Tab |
| Просмотр снимков на камере | P |
| Меню камеры | G |
| Режим вспышки (выкл, заполняющая, по второй шторке, авто) | V |
| Лупа для ручного фокуса | H |
| Режим съёмки (покадровый, серии, таймер) | B |
| Зона автофокуса (широкая, зона, точка, трекинг) | N |
| Сдвинуть точку автофокуса | стрелки |
| Открыть камеру (объектив, адаптер, телеконвертер, фильтр, вспышка, аккумулятор, ручка, карта) | Shift + ПКМ |

Дальше: поставь **фотопринтер**, вставь карту, фотобумагу и картриджи, выбери снимок и нажми «Печать».
Отпечаток можно рассмотреть (ПКМ) или вставить в **фоторамку** на стене (Shift + ПКМ по рамке меняет паспарту).
Аккумулятор заряжается в **зарядном устройстве**, на которое подан сигнал редстоуна (туда же — батарейные ручки и вспышки).
**Штатив**: поставь на землю, ПКМ камерой — закрепить, ПКМ пустой рукой — смотреть через камеру, Shift — отойти.
С таймером на 10 с можно отойти и попасть в кадр самому.
Техника изнашивается: вода и дождь (без защиты от влаги), падения, пыль при смене объектива, ресурс затвора.
Чинится в фотомастерской, пыль и влагу убирает набор для чистки.
Всё оборудование собирается в **фотомастерской** (сама она крафтится на обычном верстаке).

Каждый снимок сразу сохраняется полноразмерным JPEG с настоящим EXIF в `screenshots/realcamera/<дата>/`.
В режиме RAW рядом ложится `.PNG` (16-битные линейные данные матрицы, выглядит тёмным, как непроявленный RAW)
и `.json` с параметрами съёмки.

**Компьютер**: вставь карту памяти (два слота: A и B, для CFexpress нужен картридер). Каталог показывает
снимки карты: клик выбирает, двойной клик или «Править» открывает редактор, звёзды под миниатюрой ставят
рейтинг, «Копир.→» и «Перен.→» переносят снимок на другую карту, «Форматир.» (нажать дважды) очищает карту.

**Редактор**: вкладки «Свет» (экспозиция, контраст, света, тени, белые, чёрные), «Цвет» (температура,
оттенок, сочность, насыщенность, ч/б, профиль камеры для RAW), «Кривая» (тяни точки), «HSL» (8 цветов),
«Детали» (резкость, шумоподавление, виньетка, зерно, профиль объектива), «Кадр» (пропорции, поворот,
горизонт, рамку кадрирования тянуть мышью), «Пресеты» (сохранить свои). Ctrl+Z / Ctrl+Y — отмена и повтор,
`\` — до/после. Из RAW можно вытянуть пересвеченное небо, из JPEG — нет. Автор снимка редактирует
полноразмерный оригинал со своего компьютера, остальные — игровую копию.
«Сохранить копию» кладёт результат новым снимком на ту же карту, «Экспорт на ПК» пишет полноразмерный JPEG
с EXIF в `screenshots/realcamera/export/`.

**Плёнка.** Плёночные камеры (Nikon FM2, Leica M6, Canon EOS-1V) снимают на ролики плёнки (Portra, Ektar,
Gold, Tri-X, HP5, Delta 3200, Velvia, Provia, CineStill 800T), плёнка вставляется в слот карты (Shift+ПКМ).
ISO равен чувствительности плёнки, экрана нет: кадры увидишь только после проявки. Когда плёнка кончится,
перемотай её (меню G, «Перемотать плёнку»). Если вынуть неперемотанную плёнку на свету, она засветится.
**Проявочный бак**: плёнка + нужная химия (C-41 для цветного негатива, E-6 для слайдов, ч/б), пуш/пул, «Проявить».
Заряжать бак нужно в полной темноте (без красного фонаря рядом) или с **зарядным рукавом** в слоте бака.
Проявленную плёнку можно рассмотреть (ПКМ), напечатать на **фотоувеличителе** на фотобумаге для лаборатории
(RC, баритовая, RA-4) или отсканировать в **компьютере** со **сканером плёнки**. Фотобумагу у увеличителя можно
держать только в темноте или при **красном фонаре**, иначе отпечаток засветится.

**Фотоальбом** (книга + кожа + 3 бумаги): ПКМ — открыть, «Вставить отпечаток» берёт отпечаток из второй
руки или инвентаря, под фото можно написать подпись. Положи альбом на кафедру, и его смогут листать все.
**Настольная рамка** ставится на стол или полку, **фотостенд** (мольберт в два блока) — для выставок.
ПКМ отпечатком — вставить, ПКМ пустой рукой — посмотреть, Shift+ПКМ — забрать.

**Полный каталог** (этап 6): 39 камер и 63 объектива — Sony, Nikon, Canon, Fujifilm, Panasonic, Leica, OM System,
Hasselblad, плюс плёночные Canon AE-1, Pentax K1000, Olympus OM-1, Зенит-Е, Hasselblad 500C/M (плёнка 120, кадр 6×6)
и Contax T2. У компактов (Fujifilm X100VI, Leica Q3, Contax T2) объектив встроен и не снимается. Для чужих
объективов есть адаптеры (M42, Leica M, Canon FD, Pentax K, Olympus OM, Hasselblad V…) и телеконвертеры.
Особая оптика:
- **фишай** (M.Zuiko 8mm, Samyang 8mm) — сильная бочка, на полном кадре — круглая картинка;
- **тилт-шифт** Canon TS-E 24mm: Z / X выбирают «TILT» и «SHIFT», Ctrl+колесо меняет. Сдвиг (shift) держит
  вертикали зданий параллельными, наклон (tilt) поворачивает плоскость резкости («игрушечный город» при
  обратном наклоне). В видоискателе вертикали ещё сходятся, на снимке они ровные;
- **макро 1:1** (Sony 90mm, Nikon MC 105mm, Canon RF 100mm, Fujifilm 80mm): в видоискателе видно увеличение «1:2.5»;
- **винтаж**: Гелиос-44-2 закручивает боке в вихрь, Trioplan даёт «мыльные пузыри».
Старая техника попадается в сундуках: у картографов в деревнях (плёнка, Зенит, Гелиос), на затонувших кораблях
(утонувшие камеры на запчасти), в кладах и библиотеках крепостей (Leica M6, Hasselblad), в древних городах и
испытательных залах (многослойные и среднеформатные матрицы, Contax T2).

Команды администратора: `/photo list`, `/photo info <id>`, `/photo delete <id>`, `/photo purge <игрок>`, `/photo stats`.

## Для разработки

- `./gradlew runClientAutotest -Pautotest=stage6` — каталог, витрина камер и объективов, фишай, тилт-шифт, макро, Гелиос, X100VI, плёнка 120, лут.
- `./gradlew runClientAutotest -Pautotest=stage3` — автотест аксессуаров и износа (вспышка, фильтры, штатив, вода, ремонт).
- `./gradlew runClientAutotest -Pautotest=stage2` — автотест оптики этапа 2 (адаптеры, видоискатели, длинные выдержки, серия).
- `./gradlew runClientAutotest` — сквозной автотест этапа 1: сам строит сцену, снимает, печатает, вешает рамку,
  открывает все экраны и кладёт скриншоты в `run-autotest/screenshots/autotest/`. Результат — строки `[autotest] PASS/FAIL` в логе.
- `python3 tools/gen_assets.py` — пересоздаёт текстуры, модели и звуки; `python3 tools/gen_recipes.py` — рецепты.
- Каталог этапа 6 описан в `tools/catalog.py`: `python3 tools/gen_catalog.py` пишет JSON и названия, потом
  `gen_assets.py` и `gen_recipes.py`; лут в сундуках — `python3 tools/gen_loot.py`.
