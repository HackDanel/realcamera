# Stage 4 — computer, editor, album, displays (2026-11-05)

## What was added

- **Real RAW.** The pipeline is split into `ImagePipeline.developSensor` (optics, exposure, motion, wear, flare,
  noise; clipped at the sensor saturation `rawSaturation(DR)`, 1–3 EV above JPEG white) and `finish` (highlight
  roll-off, white balance, colour profile). RAW files are 16-bit linear PNGs of the sensor stage plus a JSON sidecar
  (`processing/RawFile`: white level, as-shot WB and profile, the camera's profile list, baked vignetting /
  distortion / CA for lens correction). Stage-2 sidecars (no `version`) are read as 8-bit sRGB frames.
- **Local originals.** `client/photo/LocalOriginals` (realcamera_cache/originals.json) maps photo ids to the
  photographer's full-size JPEG/RAW, so the author edits at full resolution; everyone else edits the in-game copy
  (`PhotoCache.loadBytes`).
- **Computer** block (two card slots A/B, CFexpress reader upgrade slot): catalogue with thumbnails, 0–5 star rating
  (stored in `PhotoIndex.Entry.rating`), delete, copy/move between cards, format (double click). A file is deleted
  only when no card holds it and it was never printed (`ServerPhotoService.removeFromCard`).
- **Editor** (`processing/PhotoEditor` + `EditSettings`, pure Java; UI `client/screen/EditorScreen`, worker
  `client/editor/EditSession`): lens profile correction, rotate 90°, straighten (auto-zoom), crop with aspect
  presets, exposure (RAW ±4 EV with highlight recovery, JPEG ±1.5 EV clipped), temperature/tint, contrast,
  highlights, shadows, whites, blacks, 5-point monotone tone curve, HSL in 8 bands, vibrance, saturation, B&W,
  camera profile (RAW), noise reduction, sharpening, vignette, grain; undo/redo, before/after, histogram,
  presets in config/realcamera/presets. "Save as copy" uploads a new photo (`PhotoMeta.editedFrom`, quota charged
  to the uploader via `Entry.uploader`) onto the same card; "Export" writes a full-size JPEG with EXIF to
  screenshots/realcamera/export/.
- **Photo album** (48 prints, captions, insert from the other hand/inventory) and **lectern** support (album in the
  `minecraft:lectern_books` tag; right-clicking the lectern is intercepted server-side and opens a read-only album
  with a "take" button).
- **Table frame** (turns portrait for tall prints) and two-block **photo stand** (easel); shared `DisplayBlock` /
  `DisplayBlockEntity` (synced print) and `DisplayRenderer`.
- Block loot tables for every block (stage 1–3 blocks dropped nothing before), generated by `tools/gen_recipes.py`.

## Verified

`./gradlew test` (44 tests; editor: identity, RAW = in-camera JPEG at defaults, RAW highlight recovery vs JPEG,
rotate, crop, spline, WB direction, HSL band isolation, tone, RAW file round trip) and
`./gradlew runClientAutotest -Pautotest=stage4`: 16-bit RAW written, "needs CFexpress reader" message, catalogue,
editor loads the RAW original, edit + save as copy, export, rating, copy to card B, format B keeps the shared file,
table frame + stand show prints, album with caption, lectern album opens and can be taken back, block drops.

## Notes

- Creative mode does not consume the print put into a frame/stand (vanilla `consume` rule).
- The autotest kit lens is APS-C, so the α7 IV shoots in crop mode (1280 px) there.
