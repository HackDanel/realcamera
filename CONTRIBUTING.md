# Руководство по участию в проекте (Contributing Guidelines)

Рады, что вы решили помочь в развитии Realcamera! Вот несколько простых правил, которые помогут сделать процесс совместной работы быстрым и эффективным.

## 🚀 Как внести свой вклад

1. **Форкните** репозиторий.
2. **Создайте ветку** для ваших изменений:
   ```bash
   git checkout -b feature/ваша-фича
   ```
   *(или `bugfix/исправление-бага`)*
   Обязательно ветвитесь от 'main'
4. **Внесите изменения** и сделайте коммиты. Пишите понятные сообщения к коммитам. Никаких add new file или fix bugs. Обязательно указать файл, который был добавлен или баг, который был починен. 
5. **Протестируйте** свои изменения, чтобы убедиться, что ничего не сломалось.
6. **Отправьте ветку** в свой форк:
   ```bash
   git push origin feature/ваша-фича
   ```
7. **Откройте Pull Request (PR)** в основную ветку нашего репозитория.

## 🐛 Как сообщить о баге или предложить идею

Если вы нашли ошибку или у вас есть идея по улучшению, пожалуйста, проверьте [список Issues](https://github.com/HackDanel/realcamera/issues), возможно, это уже обсуждается. 

Если нет, создайте новый Issue и укажите:
* Четкое описание проблемы или предложения.
* Шаги для воспроизведения багов (если применимо).
* Ваше окружение (Шейдеры, версия движка forge, версия игры, список всех модов, логи с консоли (если есть)).

Спасибо за ваш вклад! 🙌
